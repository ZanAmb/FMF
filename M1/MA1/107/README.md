Pri vztrajnostnem momentu malo bolj formalna razlaga (namesto zgolj intuicije): v koordinatnem sistemu, kjer so osi poravnane z lastnimi osmi telesa, je tenzor vztrajnostnega momenta diagonalen (na diagonali so zaradi simetrije enake vrednosti), zaradi česar je vztrajnostni moment v poljubni osi vedno enak. Pri tretji nalogi bi morda lahko še risali težišče nevtronov (ki še niso zapustili reflektorja) v odvisnosti od števila sipanj, kar bi lepo dopolnjevalo razlago narisanih izhodnih verjetnosti.
